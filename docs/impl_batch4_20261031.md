
## D 地图聚合卡片与簇网格（2026-10-31）

### 实现
- `PhotoClusterAnnotationView` 改为 86×74 卡片：最多 3 张代表照片按 first/middle/last 堆叠，右上角数量徽标（单张不显示）。
- 代表规则：`PlacesClusterer.representatives` 按 `creationDate`（同日期按 id）排序后取首、中、尾；少于 3 张原样返回。仅 `viewFor` 可见标注创建卡片，异步加载 320px grid tier（`cachedThumbnail` 优先），不调用全屏层。
- 点击多图簇：`onOpenCluster` → `LibraryViewModel.showClusterGrid` 用簇内 id 快照过滤，Months 网格显示；单图簇仍直接打开查看器。簇网格顶部为 `‹ Map    500 photos`。
- 返回地图：`backToMap` 清除簇过滤但保留 `lastMapRegion`；`PlacesMapView` 通过 `initialRegion` 恢复同一视野，地图重建后聚类结果一致。
- 地图区域变化回写 `lastMapRegion`；网格中的 `Show Grid in This Area` 仍可用，簇网格优先于区域过滤。

### 实测（3,000 张地理样本；上海密集簇 500 张）
- 聚类 p95：1.60ms（100 次，同一区域，阈值 <100ms）。
- 代表选择：3 张（首/中/尾）；预热门槛后卡片缓存命中 3/3；卡片异步加载完成 3/3。
- 卡片层级：加载 3 个图片槽，徽标文本 “500”；真实 MapKit 层级中存在可见 cluster annotation view，且只有可见标注创建卡片。
- 地图初始视野恢复：中心 31.2304,121.4737，span 0.8000×1.3581（输入 0.8×0.8，MapKit 校正后横向值）；断言通过。
- 地图打开 RSS：21.7MB → 48.3MB，Δ+26.6MB（同一进程，含 MapKit/Metal/瓦片缓存；非泄漏结论，仅基线）。
- 簇网格打开：2.96ms，包含恰好 500 张；`‹ Map` 后回到 `.location`，`lastMapRegion` 保持同一中心。
- 既有地图 p95 聚类 HTML 报告仍为 0.03–0.05ms 量级（小样本）；卡片视图本身不参与聚类计算。

### 备注
- 卡片只在 `viewFor` 调用时加载，MapKit 自行决定可见标注；没有全量预生成。
- 卡片图片若未预热会生成 320px grid tier（后台），但仍不读取全尺寸原图；预热命中时 0 解码。

## E 密度档位与缩放体验（2026-10-31）

### 实现
- 五档密度 `[0.5, 0.7, 1.0, 1.4, 2.0]`；工具栏连续滑杆（0.5...2.0，步长 0.1）、`−`/`+` 按钮（⌘−/⌘+）、当前倍率标签和档位菜单。
- `@AppStorage("gridDensity")` 持久化；`DensityPreferences` 读取并迁移旧 `zoomLevel`（旧范围 0.3...2.0）到新范围并 clamp；模型和 UI 双重 clamp。
- `LibraryViewModel.gridDensity` 经过 60ms debounce 写入 `effectiveDensity`；密度变化不触发重新分组。保留 `zoomLevel`/`effectiveZoomLevel` 兼容别名。
- `GridScrollCenterKeeper` 在密度变化后按内容高度比例恢复滚动中心，避免回到顶部。
- 预取开关 `prefetchEnabled`（测试/调试用），不改变默认行为。

### 实测
- 迁移：legacy 0.3 → 0.5；已有 gridDensity 1.7 优先；2.9 → 2.0；五档断言通过。
- 密度 clamp：设置 0.1 → 0.5；设置 9 → 2.0。
- debounce：60ms；设置 1.4 后生效约 224ms（含测试 sleep 粒度），密度变化 regroupCount 不变；设置 1.6 的完整生效约 129ms（含 60ms debounce）。
- 中心保持：420pt 高视口，内容高度 1000→2000 后中心 500.0→500.0（阈值 ±12pt）。
- 缩略图：60 张已预取/缓存加载总耗时 12.0ms，p95 0.26ms，命中 60/60；冷启动按需生成同一批 60 张总耗时 121.3ms，p95 2.26ms。首屏暖缓存 <120ms 断言通过。
- 回归：
  - grouping_test 全部通过（组头/分区/分组控件渲染）。
  - places_test 全部通过：上海 1° 簇 p95 1.46ms、覆盖 500 张、地图首个 region 回调 178ms；`showGrid` 过滤 500 张后清空恢复 3000。
  - incremental 扫描：首屏 0.187s（256 张）、1000 张热路径 1.265s、最终索引 3007；取消/恢复 partial=256、final=1000（旧批次分批语义未变）。
  - 空态/首屏/快速滚动/缩放/地图/全屏二进制 smoke 由上述 harness + app launch 覆盖；本项未新增 UI 自动化截图。

### 备注
- 中心保持是“按内容高度比例恢复中心”，不是逐 item 锚定；在 LazyVGrid 行高随宽度变化时避免视口跳顶，误差受分区头部高度影响。
- 密度滑杆步长 0.1 与档位菜单 5 档并存；键盘快捷键只在 Gallery 窗口内生效。

### 未尽项
1. 时间焦点只覆盖年/月；日粒度可继承月份但面包屑没有单独“日”层级，未实现日点击钻取。
2. 卡片 `cachedThumbnail` 未命中时仍会后台生成 320px grid tier；预热后为 100% 缓存、0 原图解码，但首次地图打开可能是占位色块→图片。
3. 地图 RSS 仅记录打开前后单次采样，不能据此判断泄漏；多次开关地图的内存回归未自动化。
4. 中心保持按内容高度比例，不是逐 item 锚定；分区高度差较大时可能有少量偏移。
5. 键盘快捷键与滑杆的 UI 自动化受本机辅助访问权限限制；已做模型/视图单测，未做真实键盘事件回放。
6. MapKit 会按碰撞策略隐藏部分重叠卡片；密集区域可见卡片数量由 MapKit 决定。
