# MediaViewer 实现批次 2 交付报告（2026-10-31）

结论：批次 2 的 5 项（含 5b）均已实现并各自独立提交到 `main`。首屏增量发布、滚动节流、
动态缩略图层、地理编码去 key + 双后端均已实测；`swift build -c release` 通过。仍有 3 个
未完全达标的点：**快速滚动 >25ms 停顿未稳定 ≤30**、**2000px 屏幕图解码耗时 213–313ms
（占位图 1–2ms 先上屏）**、**Nominatim 在当前网络不可达，仅用假后端验证了选择逻辑**。

测量环境：macOS 14 x86_64，Xcode 15.4，`swift build -c release`。样本为
`/private/tmp/mvbench`（3,007 个媒体文件；最大样张 5,760×3,840 / 4.3MB）。所有测量使用
生产代码构建的 app 副本（仅注入环境变量与计时 hook）或直接链接生产源码的独立进程；
媒体文件只读。

## 1. 扫描期间增量发布（`4d14181`，审查 §6 #1 / P0-1）

| 指标 | 批次 1 结束时 | 批次 2 | 口径 |
|---|---|---|---|
| 冷扫描首条出现 | 无（等完整索引后 1.293–1.503s） | **0.185–0.487s**，首批 256 条 | `LibraryViewModel.setRootURL → items 首次非空`；3,007 文件、空索引 |
| 首条 < 索引完成 | 否 | **是**（headless 0.185s < 1.274s；app 0.354s < 2.076s） | 同一进程内观测 |
| 热启动首批 1,000 条 | 0.242–0.249s | **0.257–0.338s** | app，已有索引 |
| 取消 | 取消后保留已提交批次 | 部分 **256** 条，`scanProgress="Cancelled"`；再次 `refresh()` → 1,000 条 / 总数 3,007 | `incremental_main` |
| 扫描完成 | 正常 | `Indexed 3007 new/changed items, 3007 total` | `incremental_main` |

实现：扫描按批提交 Core Data 并向 ViewModel 回传已提交条目；ViewModel 合并增量并按批发布，
`defer { isScanning = false }` 保持完成/取消语义。冷扫描总耗时受磁盘缓存影响在 1.27–4.36s
之间，本项验收只要求“首条早于完成”。

## 2. 全屏屏幕尺寸渐进解码（`46d821d`，审查 §6 #2 / P0-12）

| 指标 | 批次 1 结束时 | 批次 2 | 口径 |
|---|---|---|---|
| 打开 → 占位图可见 | 1024px 热占位约 6–10ms | **1.2–2.2ms**（缓存命中） | `ViewerImageLoader.placeholder` 非空 |
| 2000px 屏幕图 | 无（直接整张解码 426.8–447.4ms） | **213–313ms** | `screenImage` 赋值；长边 2000px |
| 屏幕图 RSS 增量 | 84.4MB 位图 | **+9.6–14.3MB** | 相对打开前，`task_info` RSS |
| 放大补解码 | 已是整张 | **382–420ms，+94–99MB** | 5,760×3,840 原始分辨率，缩放 ≥1.4× |
| 相邻预取 | 无 | ±2 张 1024px 后台预热 | `prefetchNeighbors` |

打开后先显示 1024px 占位图（可立即交互），2000px 屏幕图随后替换；验收中的
“≤100ms 可交互”由占位图满足，屏幕图本身需 213–313ms（22MP JPEG 解码成本），这是本项
未完全达标的部分。稳定 RSS 增量 14.3MB < 20MB 达标。

## 3. 滚动期缩略图节流（`5a55cdd`，审查 §6 #3 / P1-12）

| 12s 自动滚动（3,007 文件，1,000 条已加载） | 优化前 | 批次 2 |
|---|---|---|
| >25ms 停顿 | 92 | **20–34**（6 次 20/21/21/28/31/34） |
| >50ms 停顿 | 31 | **0** |
| >100ms 停顿 | 1 | **0** |
| max 停顿 | 255.8ms | **32–35ms** |
| 60Hz tick | 587/720 | **717–720** |
| 静止 8s 对照 | 0 | **0** |

口径：每 120ms 程序化滚动 320pt，60Hz `Timer` 记录帧间隔；>25ms 约等于低于 40fps。
>50ms、>100ms、max 三项达标；**>25ms 目标“≤30”未稳定达成**（31/34 两次超限），已从 92
降到 28–34。实现：`ScrollActivityObserver` 以滚动位移速度检测快速滑动，滑动期间暂停缩略图
生成/预取，停止 120ms 后在最新可见项附近恢复。

## 4. 动态缩略图层（`c56514c`，审查 §6 #4 / P0-6）

| 层 | 生成耗时（70 张冷） | 磁盘/张 | 位图 | 用途 |
|---|---|---|---|---|
| 320px（未改代码路径） | **9.3ms** mean，p50 7.8，p90 13.3 | **22.6KB** | 0.27MB | cell ≤160pt（zoom ≥1.0） |
| 640px（新增） | **21.3ms** mean，p50 18.4，p90 44.5 | **74.5KB** | 1.1MB | 160–320pt（zoom 0.5–0.99） |
| 1024px（全屏占位） | 27.8ms 冷 / 9.5ms 热（批次 1 数据） | — | 2.7MB | zoom <0.5 / 全屏 |

选择规则：`gridCellWidth × backingScale`，≤320→320，≤640→640，否则 1024。实测映射：
zoom 1.0→320，0.9/0.75/0.5→640，0.49/0.3→1024。缩小时切层保留旧图直到新层解码完成，不闪。
缓存：320 层 256MB（~850 张）、640 层 192MB（~176 张）、1024 层 128MB（~42 张）。
风险：zoom<0.5 浏览 3,000 张会按需生成约 **224MB** 的 640/1024 缩略图（磁盘），可接受但需
在文档中说明。

## 5. 地理编码：key 出源码 + 双后端（`ecb5582`，审查 §5 / P0-8，含批准项 5b）

- 高德 key 仅从 `MEDIAVIEWER_AMAP_KEY` 环境变量或 Info.plist `AmapAPIKey` 读取；
  缺失时本地立即失败（**0.1ms**），不发起请求。
- 选择逻辑：中国范围优先高德（GCJ-02），其他地区优先 Nominatim；任一失败自动回退另一后端。
- Nominatim：`RequestThrottle` actor 串行化到 **1 req/s**；自定义 User-Agent
  `MediaViewer/1.0 (contact: …)`，联系方式来自 `MEDIAVIEWER_NOMINATIM_CONTACT` /
  Info.plist `NominatimContact`，缺省为 `NSUserName()@localhost`；内存缓存 2,000 条；
  位置分组页展示 “© OpenStreetMap contributors (ODbL)”。
- 失败不再写永久 `Unknown Location`：新失败保留 `locationName=nil`，旧占位符在下次扫描
  重试；连续 3 次网络失败中止本轮且不写入。
- 测试：假后端 9/9 通过（国内/海外选择、双向回退、双失败、缺 key、节流 0.53s）。
- 限制：当前网络访问 `nominatim.openstreetmap.org` **10s 超时**（curl 同样超时），真实
  Nominatim 解析未验证；高德未配置 key，未做真实请求验证。
- `grep` 当前源码/配置无 key 明文；**初始 commit 历史仍含旧 key**，应尽快在控制台轮换该 key
  （重写历史需单独批准）。

## 7. 未尽项与遗留风险

1. 快速滚动 >25ms 停顿 28–34，未稳定 ≤30；进一步需要减少每帧布局/绘制成本（如
   `CALayer`/预合成），不在本批范围。
2. 22MP JPEG 的 2000px 屏幕图解码仍需 213–313ms；占位图即时可见，但屏幕图不是 100ms 内。
3. Nominatim 在当前网络不可达；真实高德请求未测（无 key）。需在目标网络分别验证。
4. 旧 Amap key 仍在 git 历史（初始 commit），当前工作树已无明文；需要轮换 key。
5. OSM 署名只在“地点”分组显示；若未来在其他位置展示地点名需补齐署名。
6. 640/1024 层按需生成会增加磁盘占用（3,000 张最多约 224MB），清理仅在条目变更/删除时。
7. 批次 3 范围（连续捏合、年月日导航、matchedGeometryEffect、Application Support、HEIC、
   视频 poster、FSEvents）未开始。
