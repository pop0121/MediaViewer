## 1. 实现摘要

- `MediaDateParser`：支持 IMG、Screenshot、扫描文件、微信图片、mmexport 10/13 位 epoch、纯数字、image_editor 等文件名模式；1990 至“现在+1 天”夹逼；非法日期/未来日期返回 nil。
- `MediaDateSource`：`exif`、`quickTime`、`filename`、`fsModified`、`fsCreated`；nil 显示“时间来源未知”。
- 日期优先级：EXIF `DateTimeOriginal` → `DateTimeDigitized` → QuickTime `creationDate` → 文件名 → 较早的 mtime（仅当早于 ctime）→ ctime → nil（“未知时间”）。这与任务书“全 2026”的旧机制相反：旧代码直接使用 ctime（批量拷贝日）。
- Core Data 新增 `derivedDate`、`dateSourceRaw`；旧 `creationDate` 保留兼容。无日期行写 `"unknown"` sentinel，避免每次启动重复提取。
- 分组、排序、时间线、地图代表图、查看器元数据面板均使用 `derivedDate`。未知日期进入“未知时间”分组，排在最末。
- 媒体扩展补齐 `.png .gif .webp`（与 jpg/jpeg/mp4/mov 合计 7 种）；`.mediaviewer` / `.database` 缓存仍跳过。
- 扫描每 256 条增量发布；启动先读取已有索引上首屏，再后台扫描。
