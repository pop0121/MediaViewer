# MediaViewer 审查与优化报告（含基线 / 优化后实测）

日期：2026-10-31
基线版本：`45fd16e`（initial commit）
优化后版本：`18c5337`
环境：Intel Core i7-8750H（6C/12T）、16GB RAM、macOS 14.6、Swift 5.10 / Xcode 15.4、`swift build -c release`

---

## 1. 结论（先行）

1. **首屏从"分钟级"降到"秒级"**。3,007 文件、空索引冷启动 → 首批 1,000 条：**88.6–98.2s → 1.29–1.50s**（约 60–70×）；热启动 **0.515–0.598s → 0.242–0.249s**。根因是原先"扫描 → 全量缩略图 → 反向地理编码"全部串行后才取第一页；现在扫描只建索引，取数立即执行，缩略图由网格按需生成，地理编码移到扫描后的可取消维护任务。
2. **一屏主线程解码从 257ms 降到约 18ms**。缩略图改为 320px 网格层 + 1024px 全屏占位层，生成时即强制解码（`kCGImageSourceShouldCacheImmediately`）；网格只绑定已解码图像。单张主线程解码 **7.6ms → 0.60ms**，30 张 **257ms → 18ms**（0.60 × 30）。
3. **缩略图尺寸/缓存匹配显示需求**。磁盘 **147KB → 36KB/张均值**，解码位图 **1.9–2.3MB → 0.07MB/张**；缓存有效容量从约 87 张升到约 850 张（网格层 256MB）。
4. **分组重排从 193–246ms 降到 2.3–2.6ms**（3,007 条）。日期 key 按 item 缓存，不再每条新建 `DateFormatter`；分页追加从 135/211/223ms 降到 19/21/8ms。
5. **确定性 bug 已修**：视频切换现在替换 `AVPlayerItem`（实测 v01→v02，rate 1.0；暂停 rate 0）；`ScanResult.removed` 不再虚报（未变更库从 "removed 6014" 变为 0）。键盘响应从"每键一个 Task 排队"改为主线程同步处理，**0.06–0.10ms/键**。
6. **仍未达到苹果照片的体验**：快速滚动 12s 仍有 **92 次 >25ms、31 次 >50ms、1 次 >100ms 停顿（max 255.8ms）**；全分辨率照片仍是整张解码（5,760×3,840：**427–447ms、84.4MB 位图**，后台线程，占位图先上屏）；扫描期间不增量发布；320px 网格层在放大单元时会变糊。这些是下一阶段的主要工作。

## 2. 测量口径

| 项 | 口径 |
|---|---|
| 样本 | 3,007 文件 / 1.1GB：3,000 张照片（70 张真实照片的 APFS clone）+ 7 段 MP4；70 张唯一照片含 4 个 GPS 坐标；最大样张 5,760×3,840 / 4.3MB |
| 冷/热 | 冷 = 删除 `<root>/.mediaviewer`；热 = 索引与缩略图已存在 |
| 首屏 | 生产代码构建的 app，仅注入 `MV_ROOT` 环境变量与计时日志；`setRootURL → $items 首次非空（1,000 条）` |
| 扫描/分组/缩略图 | `swiftc -O` 编译生产源文件成独立 harness，调用真实 `MediaScanner` / `LibraryViewModel` / `ThumbnailGenerator` |
| 主线程解码 | 对网格层图像执行 `CGImageSource` 已解码位图读取（`.cgImage` 后光栅化）计时；30 张按单张实测 × 30 |
| 滚动 | app 副本内 60Hz 主线程心跳，间隔 >25ms 记为停顿；自动滚动 320pt/120ms，持续 12s |
| 内存 | `task_info(MACH_TASK_BASIC_INFO)` RSS |
| 单位 | 时间 ms/s（墙钟，release `-O`）；内存 MB；大小 KB/MB |

样本仍为 70 张唯一照片的 clone，I/O 与页缓存偏乐观；未覆盖 HEIC / Live Photo。

## 3. 优化前后关键数字

### 3.1 启动与首屏

| 指标 | 优化前 | 优化后 | 变化 |
|---|---|---|---|
| 冷启动 → 首批 1,000 条（3,007 文件，app） | 88.6 / 98.2 / 91.0s | **1.503 / 1.293s** | 约 60–70× |
| 冷启动内部：扫描（3,007 文件，无 UI） | 37.0s（含全量缩略图） | **1.13–1.23s**（仅索引，含进度回调） | 约 30× |
| 热启动 → 首批 1,000 条（app） | 0.515–0.598s | **0.242 / 0.249s** | 约 2.2× |
| 热扫描（3,007 文件，索引已存在） | 58–70ms | **0.13s**（含 3,007 次资源读取） | 持平量级 |
| 地理编码、缩略图清理 | 串行阻塞首屏 8.3s | 扫描后异步、可取消，不阻塞首屏 | 移出关键路径 |
| `ScanResult.removed`（未变更库） | 6,014 | **0** | 修正 |
| 扫描进度 | 只有首尾文案，不可取消 | 49 次索引进度事件（节流至约 64 文件/次）+ 保存阶段；取消后事件停止 | 新增 |

### 3.2 缩略图

| 指标 | 优化前 | 优化后 | 口径 |
|---|---|---|---|
| 网格层生成（70 张，冷） | 27.4ms/张（960px，全图） | **7.87ms** mean，p50 7.17，p90 11.95，max 62.87 | 320px，优先嵌入 EXIF 缩略图 |
| 网格层热读盘 + 解码 | 0.73ms 读盘 + 主线程 7.6ms 解码 | **1.39ms** mean，p50 1.41（含解码） | 独立进程、文件已存在 |
| 网格层主线程解码 | 7.6ms/张 | **0.60ms/张**（p95 0.99） | 已解码位图读取 |
| 一屏 30 张主线程成本 | 257ms | **约 18ms** | 0.60 × 30 |
| 网格层磁盘 | 147KB/张 | **36KB/张均值** | 70 张网格 + 20 张全屏 = 3.2MB |
| 网格层位图 | 1.9–2.3MB/张 | **0.07MB/张** | 320×~213 RGBA |
| 全屏占位层（1024px） | 无 | **27.8ms 冷 / 9.5ms 热**（p50 6.81 热） | 20 张，含解码 |
| 缓存容量 | 200MB ≈ 87 张（countLimit 200 失效） | 网格 256MB ≈ 850 张；全屏 128MB ≈ 42 张 | NSCache cost = 解码字节 |
| 并发去重 | 无 | 同一路径 20 并发 → **1 个生成任务、1 个文件** | 65.1ms 完成 |

### 3.3 分组与分页

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 3,007 条重排（月） | 193–246ms | **2.32ms**（p50 2.30） |
| 3,007 条重排（日） | 193–205ms | **2.62ms**（p50 2.50） |
| 地点分组（3,007 条） | 未单测 | **2ms** |
| 分页追加（OFFSET 1,000/2,000/3,000） | 135 / 211 / 223ms | **19 / 21 / 8ms** |
| 3,007 条全量 fetch | 4–5ms + 逐条 fault 2–3ms | 2–4ms（字典/实体读取） |

### 3.4 滚动（app 副本，3,007 文件，约 1,000 条已加载）

| 场景 | >25ms | >50ms | >100ms | max | 60Hz tick |
|---|---|---|---|---|---|
| 优化前 12s 自动滚动 | 119 | 90 | 23 | 156.8ms | 377/720 |
| 优化后 12s 自动滚动 | **92** | **31** | **1** | **255.8ms** | **587/720（81.5%）** |

优化后这一轮滚动期间仍在按需生成 320px 缩略图，属"冷缩略图 + 快速滚动"组合；已明显改善，但未达到"静止水平"。

### 3.5 全屏查看器

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 最大样张 5,760×3,840 / 4.3MB | `NSImage(contentsOf:)` 主线程加载 6.0ms + **绘制解码 502.7ms**；位图 84MB；RSS 140→318MB | 后台 ImageIO 解码 **426.8 / 447.4ms**；位图 84.4MB；主线程先显示 1024px 占位（约 6–10ms 热）；切换不黑屏 |
| 键盘导航 | 每键 `Task` 排队，含 50ms 采样窗测量 229–247ms | **0.06–0.10ms/键**（主线程同步处理） |
| 视频切换 | 继续播放上一段 | 实测 `currentItem=v02.mp4`、rate 1.0；暂停 rate 0 |
| 相邻预取 | 无 | ±2 张 1024px 占位后台预热 |
| 开合过渡 | 无动画的 opacity | 0.18s opacity + scale(0.98) |
| 日期头 | 随内容滚走 | `pinnedViews: [.sectionHeaders]` 吸顶 |

### 3.6 内存

- 3,007 条 `MediaItem` + 分组：RSS **17–18MB**（首次 1,000 条增量约 +2MB）。
- 网格层缓存上限 256MB（约 850 张），全屏层 128MB（约 42 张）；单张全分辨率位图仍为 84MB（未做屏幕尺寸降采样）。

## 7. 与苹果照片 App 的差距

| 维度 | 苹果照片 | 当前实现 | 状态 |
|---|---|---|---|
| 即时滚动 | 预解码纹理，滚动不掉帧 | 320px 已解码缩略图 + 预取 ±24；快速滚动仍有 92 次 >25ms | 改善，未达标 |
| 渐进式缩略图 | 低清占位 → 高清 | 网格按需生成，无两级渐进；首屏前要等索引 | 部分 |
| 预取 | 按方向预取多屏 | 网格 ±24、查看器 ±2（1024占位） | 部分 |
| 日期分组 | 吸顶、年/月/日/全部、侧边索引、捏合缩放 | 吸顶已实现；层级/本地化/手势缺失 | 部分 |
| 缩放自适应 | 连续捏合、单元尺寸动画、分层缩略图 | 滑杆 0.1 步进；320px 固定层 | 差距明显 |
| 全屏过渡 | 匹配几何放大 + 交互式关闭 | opacity+scale 0.18s | 部分 |
| 全屏画质 | 屏幕尺寸渐进解码 | 占位 1024 → 整张原图（427ms/84MB） | 差距明显 |
| 视频 | 内联预览、无缝切换、进度 UI | 切换 bug 已修；无 poster/预载 | 部分 |
| 索引位置 | 系统图库（Photos Library） | 媒体目录下 `.mediaviewer` | 需迁移 |

## 8. 复现方式

Harness 位于 `/private/tmp/mvbench`（未入库）：

```bash
# 生产代码构建
swift build -c release

# 单文件缩略图/解码（70 张唯一照片）
/tmp/mvbench/probe2 /private/tmp/mvbench/lib cold
/tmp/mvbench/probe2 /private/tmp/mvbench/lib warm

# 扫描进度 + 取消（3,007 文件）
/tmp/mvbench/scanprogress

# 分组/分页/热首屏（3,007 文件）
/tmp/mvbench/bench /private/tmp/mvbench/lib3k_clone warm

# 并发去重 / 取消语义
/tmp/mvbench/dedup

# 键盘导航 / 视频切换
/tmp/mvbench/viewerkeys
/tmp/mvbench/videoswitch

# app 内首屏与滚动（MV.app 由 /tmp/mvbench/make_app.sh 构建）
MV_ROOT=/private/tmp/mvbench/lib3k_clone /tmp/mvbench/MV.app/Contents/MacOS/MediaViewer
MV_ROOT=/private/tmp/mvbench/lib3k_clone MV_SCROLL_BENCH=1 MV_SCROLL_SECONDS=12 \
  /tmp/mvbench/MV.app/Contents/MacOS/MediaViewer
```

计时日志开关：`MEDIAVIEWER_TIMING=1`（写入 `os.Logger` 的 `perf` 分类，同时始终发送 signpost）。
