## 项 A：时间粒度与 zoom 解耦（`8b0e6ce`）

### 行为

- 顶部分段控件：**All / Years / Months / Days**；默认 **Months**。分段控件是唯一的时间
  分组来源，不再有 None/Date 的隐式映射。
- 滑杆只改格子大小：左端 **Small**、右端 **Large**，向右格子变大。
  `gridCellWidth = max(60, 160 × zoom)`，zoom 0.3–2.0 → 60–320pt。
- 批次 2 的层级选择保持不变：cell×backingScale ≤320→320 层，≤640→640 层，否则 1024。
  滑杆只触发层级重选与布局，不触发 regroup。
- **Places** 作为第五段，切到地图；时间分段与地图互斥。

| 检查 | 结果 | 口径 |
|---|---|---|
| 滑杆连续拖动 regroup 次数 | **0** | 0.3→2.0 共 18 步，每步等待 170ms，`regroupCount` 不变 |
| 滑杆改变分组输出 | 否 | `groupedItems` 完全相同 |

## 项 B：Places = MapKit 地图聚类（`1be7f7e`）

### 行为

- Places 模式使用 `MKMapView`（NSViewRepresentable），系统 MapKit，无 API key、无新增
  外部服务；代码中网络域名仍只有既有的高德/Nominatim 两个地理编码端点。
- 聚类：按当前可见区域（含 15% margin）做经纬度网格；从 4×4 到 32×32 选择使簇数落入
  **20–60** 的网格，簇坐标取成员平均；全部本地 O(n) 计算。
- 区域变化（平移/缩放）debounce **120ms** 后重算；MapKit 在这里只负责渲染与手势。
- 簇显示 `glyphText=数量`；点数量簇 → setRegion 到簇边界并自动细化；单张照片簇 →
  直接打开全屏查看器。
- “Show Grid in This Area”把当前地图区域写入 `GeoBounds`，切到 Months grid 并只显示
  区域内条目；工具栏可 Clear Map Area。
- 无 GPS（`nil` 或 `0,0`）照片不进入地图；工具栏显示 `N without location`。
- 地点名只用已有 `locationName` 缓存，不触发反向地理编码；geocode 更新后地图签名变化，
  注释标题在下一轮聚类刷新，不阻塞交互。
- 地图视图打开后按需拉取全部分页（网格仍保持分页），新批次到达时在用户未操作地图前
  自动重新 fit 全量区域。

## 未尽项与风险

1. **捏合连续缩放**（`MagnificationGesture` 连续更新、双指缩放整体网格）仍不在本批，沿用
   滑杆 + 层级切换。
2. **地图簇数目标为近似值**：少量/稀疏数据可能显示 <20 个簇（app 首批 1,000 条时 19 个），
   全量后为 20；地图瓦片离线时仍可聚类但底图可能空白。
3. **`0,0` 坐标被视为无位置**；跨越 ±180° 经线的地图区域过滤未特别处理。
4. **地图区域过滤状态**会保留到用户点 Clear Map Area；切到 Places 时自动清除，切回时间分段
   不会自动清除。地点名缓存若在地图打开后异步更新，注释标题会在下一次聚类刷新时更新。
5. 测试库没有真实 locationName（Nominatim 在当前网络不可达），因此验证的是“计数/文件名+
   缓存读取路径”，不是实际地名文本。
6. 本批未改地理编码服务本身；此前遗留的旧 Amap key 仍在 git 历史，需轮换。
